# Privacy

 This site is hosted on a Raspberry PI in my house and I live in England. Northumberland to be reasonably precise.  It's a personal website and from a privacy perspective, there's very little to go over, but there are a few things that may irk some people.

 For the sake of clarity though I, Jamie Curle (me@jamiecurle.com) would be considered the Data Controller. Data is processed using legitimate interest.

## Data Processors


### Cloudflare

I use Cloudflare extensively in this website and I expect that will upset some people. What about sovereignty I hear you claim? Honestly, I don't care.  It's the internet, it's a personal website and I really don't care if it goes offline for a few hours or a few days. The world will continue just fine.

But you should know that the Elixir processes that run this site are connected through a Cloudflare tunnel where it is terminated by Cloudflare and served to the internet. Images and video are served via Cloudflare also, using their R2 storage.

Obviously, this means that by visiting this site Cloudflare is going to do what Cloudflare does and for you that means that Cloudflare may place one or more cookies on your machine. You can read more about that on [Cloudflares Cookie](https://developers.cloudflare.com/fundamentals/reference/policies-compliances/cloudflare-cookies/) page.   

These cookies are strictly necessary for Cloudflare to provide its service.

One thing worth noting is that I am in the UK and Cloudflare is a US based company. For the sake of transparency the data Cloudflare need to process the request is transferred using the [UK-US Data Bridge](https://www.gov.uk/government/publications/uk-us-data-bridge-supporting-documents/uk-us-data-bridge-factsheet-for-uk-organisations) adequacy decision transfer mechanism.


## Data Collected

I don't store any personal data about any visitor. I use home rolled analytics that logs only the url of the visitor, the date of the visit, any referrer present in the request and, if set by Cloudflare, the country of visitor.  Whilst I could in theory read the IP address supplied to me by Cloudflare of what it considers to be your IP address, I don't read it. I've got no reason to store any personal data at this time.

## Retention Period

I keep my analytics data in perpetuity so that I can gauge the performance of the website. But again, there's nothing to identify you in any of that data.

## Your Rights

I love that you have them, but there's no data here for you to exercise them on.
